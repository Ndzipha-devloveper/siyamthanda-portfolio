# Siyamthanda Ndzipha — Portfolio

A personal portfolio website for presenting my background and work as a Java
developer and peer tutor. It brings my education, skills, projects, tutoring,
and contact details together in one place.

## Features

- Terminal-inspired visual design and responsive layout.
- Navigation between the About, Education, Skills, Projects, Tutoring, and
	Contact sections.
- Animated page loading and skill indicators.
- Contact form for sending messages without leaving the site.

## Built with

- HTML
- CSS
- JavaScript
